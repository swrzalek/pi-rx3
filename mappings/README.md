# Controller profiles

`Pioneer-DDJ-FLX4.rx3.xml` is the experimental FLX4 input profile. The default FLX6 mapping is fetched by `./rx3 mapping` and kept under `work/`.

See [controller configuration, supported controls and limitations](../docs/controllers.md). The bridge translates XML input bindings without running Mixxx JavaScript; neither profile claims complete controller support or hardware acceptance.
